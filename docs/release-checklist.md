# 配布前の確認事項

複数のキャラクターが完成してから、配布と紹介記事を公開します。

- [x] 複数のキャラクターの素材が揃っている（画面ロボ・少佐・cat・Cyber Boy・Cyber Girl）
- [ ] 各キャラクターの最終デザインを確認している
- [ ] 完成素材とプレビューが一致している
- [ ] 全キャラクターのファイル名、形式、サイズ、透過、フレーム配置を検査している
- [ ] アニメーションの種類と動きを確認している
- [ ] 実際に確認したアプリと導入方法を記載している
- [ ] 確認していない互換性や機能を明示している
- [ ] 配布パッケージの内容を確認している
- [ ] 利用条件が決まり、明記されている
- [ ] リポジトリと配布物に不要な個人情報や認証情報がない
- [ ] 公開範囲と公開タイミングを確認している
- [ ] 紹介記事の内容と配布物が一致している

- [x] 緑色の画面表示・黄色い電球のプレビューを確認
- [x] 既存キャラクターの更新と登録後シートの画素一致を確認
