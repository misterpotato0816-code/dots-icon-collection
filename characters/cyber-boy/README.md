# Cyber Boy

黒髪に青い差し色、大きなヘッドホンと青黒のテックウェアの男性キャラクターです。

![Cyber Boy の主な動き](previews/preview-stills.png)

## 素材

- [透明 PNG スプライトシート](assets/spritesheet.png)
- 形式：Pets v2
- 画像サイズ：1536 × 2288 px、RGBA
- 配置：8 列 × 11 行、1 コマ 192 × 208 px
- 使用コマ：73 コマ、未使用の透明セル：15 コマ
- ファイルサイズ：2,719,461 bytes

## アニメーション

1. `idle` — 待機、6 コマ
2. `running-right` — 右への移動、8 コマ
3. `running-left` — 左への移動、8 コマ
4. `waving` — あいさつ、4 コマ
5. `jumping` — ジャンプ、5 コマ
6. `failed` — 失敗時の表情、8 コマ
7. `waiting` — 返事や入力を待つ動き、6 コマ
8. `running` — 作業中・考え中、6 コマ
9. `review` — 結果の確認、6 コマ
10. 視線 0°〜157.5° — 8 コマ
11. 視線 180°〜337.5° — 8 コマ

### 表情と仕草

- `running`：腕を組んで集中して考える
- `review`：確認する、気づいて顔を上げる、手を開いて結果を伝える

説明する仕草は `review` に含まれます。独立した回答中イベントや音声同期には対応していません。

状態の切り替えタイミングはアプリが制御します。
